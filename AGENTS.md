# Agent instructions

- Mark every intentional workaround, compatibility hack, temporary shim, or deliberately incomplete implementation in code with a `// REVISIT: ...` comment.
- The `// REVISIT:` comment must explain what should replace the workaround, not merely restate that it is temporary.
- Do not introduce new `TODO`, `HACK`, `XXX`, or vague workaround comments in code without a corresponding `// REVISIT:` line.
